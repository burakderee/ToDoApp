ToDoApp, kullanıcıların günlük görevlerini organize edebileceği, kategorilere ayırabileceği ve hava durumu verileriyle birlikte planlama yapabileceği gelişmiş bir Android uygulamasıdır.

## 🚀 Özellikler

* 🔐 Kullanıcı kayıt ve giriş sistemi (Login / Register)
* 📝 Görev ekleme, silme ve güncelleme
* 📂 Görevleri kategorilere ayırma
* ☁️ Hava durumu entegrasyonu ile planlama desteği
* ✔️ Görev tamamlama (Check sistemi)
* 🎨 Modern ve kullanıcı dostu arayüz

## 🛠️ Kullanılan Teknolojiler

* Kotlin
* Android Studio
* MVVM Architecture
* Room Database
* REST API (Hava durumu verisi için)
* Material Design

## ⚙️ Kurulum

1. Bu repoyu klonlayın:

```bash
git clone https://github.com/burakderee/ToDoApp.git
```

2. Android Studio ile açın

3. Gerekli bağımlılıkların yüklenmesini bekleyin

4. Uygulamayı çalıştırın

## 🎯 Proje Amacı

Bu proje, Android geliştirme sürecinde modern mimari yaklaşımlar (MVVM), yerel veritabanı yönetimi (Room) ve API entegrasyonlarını öğrenmek amacıyla geliştirilmiştir.

## 📌 Not

Proje geliştirme sürecinde kullanıcı deneyimi ve modüler yapı ön planda tutulmuştur.
