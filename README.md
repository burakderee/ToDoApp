# 📱 ToDoApp - Gelişmiş Görev Yönetim Uygulaması

ToDoApp, kullanıcıların günlük görevlerini organize edebileceği, kategorilere ayırabileceği ve hava durumu verileriyle birlikte planlama yapabileceği gelişmiş bir Android uygulamasıdır.

## 🚀 Özellikler

* 🔐 Kullanıcı kayıt ve giriş sistemi (Login / Register)
* 📝 Görev ekleme, silme ve güncelleme
* 📂 Görevleri kategorilere ayırma
* ☁️ Hava durumu entegrasyonu ile planlama desteği
* ✔️ Görev tamamlama (Check sistemi)
* 🎨 Modern ve kullanıcı dostu arayüz

## 🛠️ Kullanılan Teknolojiler

* Kotlin
* Android Studio
* MVVM Architecture
* Room Database
* REST API (Hava durumu verisi için)
* Material Design
